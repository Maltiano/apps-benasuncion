Privacy policy

Ben AI Gmail · Last updated 27 October 2026

Who uses this app

Ben AI Gmail is a private tool operated by Ben Asuncion for his own use. It connects only to Google accounts that he owns and has authorized himself. It is not available to anyone else.

What data it accesses

With the owner's permission, the app uses the Gmail API to send email, create drafts, read the account's list of verified "send mail as" addresses, and read messages in the owner's own mailboxes.

How the data is used and stored

Data is used only to carry out tasks the owner asks for, such as drafting or sending a message or finding an email. Authorization tokens and any retrieved data stay on computers controlled by the owner and are not sent to any other party.

The app does not sell, rent, share or transfer Google user data, does not use it for advertising, and does not use it to train machine-learning or AI models.

Google API Services User Data Policy

Ben AI Gmail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
